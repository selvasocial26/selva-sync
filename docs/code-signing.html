Code Signing Policy

Selva Sync · Last updated: 25 October 2026

Signing

Free code signing provided by SignPath.io, certificate by SignPath Foundation.

Status: our application to SignPath Foundation is in progress. Until it is approved, Windows releases are not signed, and Windows may show "Windows protected your PC" (click More info → Run anyway). This page will be updated when signed releases start.

Only SelvaSync.exe published on the project's GitHub Releases page is signed. Copies from anywhere else are not ours.

How releases are built

  • All source code is public in the selva-sync repository under the MIT licence. It uses only the Go standard library, with no other code.
  • Every release is built automatically by GitHub Actions from a version tag in that repository, using the build script and workflow that are also in the repository. Nobody builds release files by hand.
  • The automated tests run before every build.
  • Each signing request is approved manually by the approver below, after checking that it comes from the expected release.

Privacy

Selva Sync sends your chosen files only to your own Google Drive, using Google's sign-in. It sends nothing to the developer or to any other system. See the Privacy Policy and Google's privacy policy.

What the app changes on your PC

Before installing, the app asks for confirmation. It installs for your Windows user only (no administrator rights), adds a Start menu shortcut, an entry in Windows "Apps", and starts with Windows (can be turned off). It can be uninstalled at any time from Windows Settings → Apps or from the app's About page.

Verify a download

  • Each release lists a SHA-256 checksum (SelvaSync.exe.sha256). In PowerShell: Get-FileHash .\SelvaSync.exe and compare.
  • For signed releases: right-click SelvaSync.exe → Properties → Digital Signatures.

Report a problem

If you find a suspicious file or a signing problem, please open an issue in the source code repository or contact Dr. Selvakumar Vellingiri via LinkedIn.
